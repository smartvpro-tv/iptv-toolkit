iptv-toolkit

A free command-line tool to inspect, check, clean and merge M3U / M3U8 playlists, and to measure the real speed you get from a stream. Zero dependencies, runs anywhere Python 3.8+ runs.

Get startedView on GitHub

$ pip install git+https://github.com/smartvpro-tv/iptv-toolkit.git
$ iptv-toolkit --version
iptv-toolkit 1.0.0

What it does

CommandWhat you get
infoNumber of channels and groups, duplicate URLs, entries with no EPG id or logo, EPG source.
checkTests every stream in parallel. Marks each one OK, DEAD, TIMEOUT or ERROR and can save a playlist with only the working ones.
cleanRemoves duplicate URLs and sorts by name or group.
mergeCombines several playlists into one, without duplicates.
filterKeeps or drops channels by group or by a name pattern.
speedDownloads from one stream for a few seconds and tells you if your line can play SD, HD, Full HD or 4K.

Why test speed to the stream?

A normal speed test measures your line to a test server close to you. That number can look great while a channel still buffers, because the path to the stream server is different, busier, or throttled. iptv-toolkit speed downloads real video segments from the stream itself, so the result matches what your player sees.

$ iptv-toolkit speed "http://your-provider.example/live/channel/index.m3u8"
Throughput  : 17.1 Mbps
Result: this connection can play Full HD (1080p) smoothly.
