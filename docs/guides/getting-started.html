Getting started

Two minutes from nothing to your first playlist report.

1. Install Python

  • Windows: install Python from python.org and tick Add python.exe to PATH during setup.
  • macOS: Python 3 comes with the Xcode command line tools (xcode-select --install), or use Homebrew: brew install python.
  • Linux: already installed on most systems. Check with python3 --version.
  • Android: install Termux, then run pkg install python git.

2. Install iptv-toolkit

$ pip install git+https://github.com/smartvpro-tv/iptv-toolkit.git

No admin rights? Add --user. Prefer not to install? Clone the repo and run python -m iptv_toolkit from the folder.

3. Get your playlist

Your provider gives you either an M3U link (it usually ends in .m3u or contains type=m3u) or a file. Both work: every command accepts a path or a URL. Keep the link private, it usually contains your username and password.

4. Your first report

$ iptv-toolkit info playlist.m3u
$ iptv-toolkit check playlist.m3u -n 30

-n 30 checks only the first 30 channels, which is enough to see if the service answers at all. Drop it to check everything.

5. Keep only what works

$ iptv-toolkit check playlist.m3u --save-working working.m3u
$ iptv-toolkit clean working.m3u -o final.m3u --sort group

Load final.m3u into your player (VLC, TiviMate, IPTV Smarters, Kodi…).

6. Test your speed to the stream

Copy the URL of one channel from the playlist (any line that does not start with #) and run:

$ iptv-toolkit speed "PASTE-THE-CHANNEL-URL"

If the result is lower than the quality you want, go to the buffering guide.
